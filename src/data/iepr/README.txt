This data is able to be scraped, but it is very easy to download, as there is only two files.
They can be found at this link:
https://www.energy.ca.gov/data-reports/reports/integrated-energy-policy-report-iepr/2024-integrated-energy-policy-report-0

The relevant files are CEDU 2024 Baseline Forecast - Total State file (or whatever more recent year) in "Baseline Demand Forecast Files"
and also CED 2024 Peak Forecast (or whatever more recent year) in "Hourly Demand Forecast Files"
